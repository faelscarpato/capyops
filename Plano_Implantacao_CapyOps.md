🚀 Plano de Implantação Tática: CapyOps v2.0Objetivo: Transformar o CapyOps de um dashboard passivo em um Agente Autônomo de Gestão de E-commerce.Estratégia: "Normal-first" (Automação da rotina, gestão da exceção).📅 Fase 0: Fundação (D-Zero - Amanhã)Antes de codar a integração, você precisa da conta criada.Criação da App no MELI Developers:Assim que tiver a conta ML, acesse developers.mercadolibre.com.br.Crie uma nova Aplicação.Redirect URI: Configure para seu ambiente local (http://localhost:5173) e produção.Output: Você terá App ID, Secret Key.Mecanismo de Autenticação (OAuth):O CapyOps precisa de um botão "Conectar com Mercado Livre".Isso gera um Access Token (dura 6h) e um Refresh Token (dura 6 meses).Automação: O sistema deve renovar o token sozinho em background.🔌 Fase 1: O Sistema Nervoso (Webhooks & Vendas)Objetivo: Parar de digitar vendas manualmente.1. Webhooks (Notificações)Em vez de ficar perguntando pro ML "tem venda nova?", o ML avisa o CapyOps.Tópico orders_v2: Assim que pingar venda -> Edge Function no Supabase recebe -> Grava no Banco -> Deduz Estoque.Tópico items: Se você pausar um anúncio no ML, o CapyOps atualiza o status local.2. Cadastro Automático de Cliente (CRM)No JSON da venda (orders), vêm os dados do comprador (snippet buyer).Ação: O sistema verifica se o CPF/ID já existe na tabela clients. Se não, cria. Se sim, atualiza e vincula a venda.Pós-Venda: O sistema marca a venda com a flag auto_message_sent: true (apenas informativo, já que usaremos a automação nativa do ML para evitar bloqueios).💬 Fase 2: Atendimento Real-Time (Perguntas)Objetivo: Tempo de resposta < 10 min (Fator crucial para reputação).Monitoramento:Webhook tópico questions.Interface CapyOps:Criar um menu "Perguntas Pendentes".Exibir a pergunta + foto do produto + link direto para responder.Lógica de Ouro: A notificação no CapyOps só some quando o Webhook retornar status answered ou quando você postar a resposta via API do CapyOps.🕵️ Fase 3: Inteligência de Mercado (Espião & Estoque)1. Espião de Preços (Price Spy)Como funciona sem violar regras:Você cadastra o MLB-ID do concorrente no cadastro do seu produto.Job Agendado (Cron): A cada 6 horas, o sistema consulta a API pública https://api.mercadolibre.com/items/{MLB_CONCORRENTE}.Alerta: Se price_concorrente < seu_price, gera um alerta no Dashboard: "Oponente baixou para R$ 99. Sugestão: Baixar para R$ 98 (Margem segura de 12%)."2. Estoque Preditivo (Runway)Mudar a lógica de "Estoque Baixo" estático.Nova Fórmula: Dias de Cobertura = Estoque Atual / Média de Vendas Diárias (Last 30 days).Alerta Inteligente: "Atenção: Seu estoque de Resina dura apenas mais 4 dias." (Muito melhor que apenas dizer "tem 5 unidades").🖨️ Fase 4: Expedição (ZPL & Logística)Etiquetas ZPL:Endpoint: /shipment_labels.O CapyOps baixa o ZPL (código de impressora térmica) ou PDF.Impressão: Via browser, abrir o PDF gerado diretamente na caixa de diálogo de impressão.Futuro: Instalar um serviço local (QZ Tray) para imprimir silenciosamente sem abrir janelas.🛠️ Arquitetura Técnica SugeridaBackend: Supabase Edge Functions (Deno/Node) para receber os Webhooks (é o jeito mais barato e escalável).Banco: Tabelas novas integrations_config (tokens), meli_orders, competitors_tracking.Frontend: React query para polling leve de status se necessário.📝 Resumo do que implantar (Checklist)[ ] Tabela de Configuração de API (Tokens)[ ] Edge Function para receber Webhook (Router)[ ] Lógica de processar order_created -> rpc_apply_sale[ ] Interface de Perguntas e Respostas[ ] Crawler de Preço de Concorrente (via API pública)[ ] Botão "Imprimir Etiqueta" na listagem de vendas
