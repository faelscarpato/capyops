CAPYOPS AGENT DIRECTIVESCONTEXTO: Este arquivo serve como contexto base para IAs de codificação (Cursor, Windsurf, Copilot CLI) trabalharem no repositório CapyOps.1. Identidade do ProjetoNome: CapyOps (Sistema Operacional para Mercado Livre)Stack:Frontend: React (Vite) + TypeScript + TailwindCSSBackend/Baas: Supabase (Postgres + Auth + Edge Functions + RLS + RPCs)Filosofia: "Normal-first" (Priorizar o fluxo feliz e a performance operacional).Status: MVP funcional (Manual). Fase atual: Automação via API do Mercado Livre.2. Regras de DesenvolvimentoBanco de Dados (Supabase)Lógica no Banco: Sempre que uma operação envolver integridade financeira ou de estoque (ex: vender, repor), use Postgres Functions (RPC). Não confie no frontend para cálculos críticos.Tipagem: Sempre gere os tipos TypeScript baseados no schema do Supabase (database.types.ts).Snake_case: Tabelas e colunas em snake_case.CamelCase: Variáveis e funções TypeScript em camelCase.Integração Mercado Livre (MELI)Webhooks: Utilize Supabase Edge Functions para ouvir notificações do tópico orders, questions e items.Tokens: Nunca exponha access_token ou client_secret no frontend. Armazene em vault ou tabelas protegidas com RLS estrito.Resiliência: Se a API do ML falhar, o sistema deve falhar graciosamente (ex: fila de retry).3. Funcionalidades Prioritárias (Roadmap)A. Integração de Vendas (Sync)Gatilho: Webhook orders_v2.Ação:Verificar se order_id já existe.Mapear order_items para os product_id internos (via SKU).Executar RPC apply_sale automaticamente.Criar/Atualizar registro na tabela customers com dados do buyer.Salvar metadados fiscais (NF-e status, shipping ID).B. Módulo de Perguntas (Q&A)Gatilho: Webhook questions.UI: Painel Kanban ou Lista de "Perguntas Pendentes".Ação: Permitir resposta via input no CapyOps -> POST /answers na API MELI -> Marcar como respondida localmente.C. Espião de Preços (Competitor Intelligence)Estrutura: Nova tabela competitor_tracking (id, my_product_id, competitor_mlb_id, last_price, target_price).Lógica: Cron job diário consultando GET /items/{id}.UI: Alerta visual no Dashboard se competitor_price < my_price.D. Lógica de Estoque PreditivoDepreciar: Lógica simples de stock <= min_stock.Implementar: Runway Logic.Calcular avg_daily_sales (média móvel 30d).days_remaining = current_stock / avg_daily_sales.Alerta se days_remaining < lead_time_provider.4. Diretrizes de UI/UXEstilo: Manter padrão "Clean/Industrial". Fundo claro, fontes legíveis (Inter/Roboto).Feedback: Todo botão de ação assíncrona deve ter estado de loading e toast de sucesso/erro.Mobile-first: A operação acontece muitas vezes pelo celular no galpão. O layout deve ser responsivo.5. Comandos ÚteisStart: npm run devBuild: npm run buildSupabase Types: npx supabase gen types typescript --project-id "$PROJECT_ID" > src/lib/database.types.ts
